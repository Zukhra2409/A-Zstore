# A&Z Store

**A&Z Store** — это проект про интернет магазина подарков, созданный для демонстрации навыков в веб-разработке (HTML, CSS, JavaScript, jQuery, Bootstrap).  
Сайт показывает, как можно создать современный, адаптивный и удобный магазин с базовым функционалом.


## Основные страницы

- **index.html** — главная страница с приветствием, категориями и каруселью товаров.  
- **product.html** — каталог с цветами, шоколадом, одеждой и аксессуарами.  
- **favorites.html** — страница с избранными товарами.  
- **cart.html** — корзина с подсчётом общей суммы.  
- **order.html** — форма оформления заказа с вводом имени, телефона и адреса.  
- **register.html** — страница входа и регистрации пользователя.  


## Основные функции

- 🔍 Поиск товаров с подсказками  
- ❤️ Добавление в “Избранное”  
- **Add to cart** Добавление товаров в корзину и подсчёт суммы  
- **Order** Оформление заказа с проверкой данных  
- **Night mode🌙** Переключение между дневным и ночным режимом  
- **Register** Простая форма входа/регистрации с проверкой email и пароля  


## Особенности проекта

- Лёгкий, чистый и понятный код, оформленный по принципам чистого кода  
- Используются **анимации и hover-эффекты** для улучшения визуального восприятия  
- Весь интерфейс выполнен в едином розово-белом стиле  
- Проект запускается локально без сервера 


## Как запустить

1. Скачайте или клонируйте репозиторий  
2. Откройте файл **index.html** в браузере  
3. Навигация и функции будут работать сразу
